## 5. 关键实现（教学要点）

1. **位图冲突检测**：96 bit（15 分钟/格）整数位图，`occ & bits != 0` 即冲突；生成端与校验端各自独立实现 `make_bitmap`。
2. **库存账本 Ledger**：`booked[] / ops[] / last[]` 三个平行数组，预约时逐片 `try_book`（失败回滚），落盘时直接回填——保证 `booked`、`version`、`update_time` 三者同源。
3. **加权采样 O(log n)**：预计算累积权重数组 + `bisect`（用户 10,003 权重、座位 3,000 权重、时段 14 权重）。
4. **"先取消后重约"**：1% 历史单附带更早的 CANCELLED 同片记录（7,752 条）——`uk_reserved(slot_id,user_id,active_key)` 中终结态 active_key 为 NULL 不参与唯一性，两条记录合法共存（阶段 3+ 演示查询）。
5. **滚动窗口模型**：座位/场馆片只保留未来 14 天（历史片归档，`slot_id` 置 NULL）；讲座片按场次保留 30 天。
